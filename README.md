# rest — замер скорости скачивания

Консольный скрипт на Node.js для замера скорости скачивания. Он делает **10 последовательных HTTP(S)-запросов** к указанному адресу, ждёт полного ответа на каждый и выводит:

- время каждого запроса и время до первого байта (TTFB);
- среднее, минимальное и максимальное время запроса;
- общий объём скачанных данных;
- скорость скачивания.

Внешних зависимостей нет, используются только встроенные модули Node.js (`http`, `https`, `perf_hooks`, `util.parseArgs`, `node:test`).

## Требования

- Node.js **18.3+**. Проверено на Node.js 24.

## Запуск

```bash
git clone https://github.com/Amir01020/rest.git
cd rest

node bin/speedtest.js https://proof.ovh.net/files/10Mb.dat
```

Можно и через npm:

```bash
npm start -- https://proof.ovh.net/files/10Mb.dat
```

Или поставить глобально как команду `speedtest`:

```bash
npm link
speedtest https://proof.ovh.net/files/10Mb.dat
```

### Опции

| Опция | Описание | По умолчанию |
|---|---|---|
| `-n, --count <N>` | количество последовательных запросов | `10` |
| `-t, --timeout <сек>` | таймаут: сколько секунд ждать, если соединение перестало получать данные | `30` |
| `--cache-bust` | добавляет к URL уникальный параметр `?_speedtest=<uuid>` и заголовок `Cache-Control: no-cache`, чтобы обойти кэш CDN или прокси | выкл. |
| `--keep-alive` | использует одно TCP/TLS-соединение для всех запросов | выкл. |
| `--json` | выводит результат в JSON, чтобы его могли читать другие программы | выкл. |
| `-h, --help` | показывает справку | |

## Единицы измерения

| Величина | Единица |
|---|---|
| Время | миллисекунды (**мс**) |
| Объём | байты в десятичной системе: 1 КБ = 1 000 Б, 1 МБ = 1 000 000 Б |
| **Скорость (основная)** | **мегабиты в секунду (Мбит/с)**, 1 Мбит = 1 000 000 бит |
| Скорость (дополнительная) | мегабайты в секунду (МБ/с), 1 МБ/с = 8 Мбит/с |

Основная единица — Мбит/с, потому что в ней указывают скорость провайдеры и сервисы вроде Speedtest. Значения можно сравнивать напрямую.

## Как считается

- **Время запроса** — от отправки запроса до получения **последнего байта** тела ответа. Сюда входят DNS, TCP/TLS-рукопожатие и редиректы.
- **Среднее время** = сумма времени успешных запросов / их количество.
- **Объём** — сумма байт, реально полученных в телах ответов. Скрипт отправляет `Accept-Encoding: identity`, чтобы сервер не сжимал ответ и считались настоящие байты.
- **Скорость** = общий объём / суммарное время запросов:

  ```
  скорость (Мбит/с) = (байты × 8 / 1 000 000) / (суммарное время в мс / 1000)
  ```

  Скорость считается по суммарному объёму и суммарному времени, а не как среднее скоростей отдельных запросов. Так короткие запросы не искажают результат.

## Поведение и надёжность

- Запросы идут **строго последовательно**: следующий начинается только после того, как полностью получено тело предыдущего. Это проверяет тест.
- По умолчанию на каждый запрос открывается **новое соединение**, и время рукопожатия входит в замер. С `--keep-alive` соединение переиспользуется, и замер ближе к пропускной способности канала.
- Скрипт следует редиректам 3xx, максимум 5.
- Если ответ пришёл не полностью (меньше байт, чем в `Content-Length`, или соединение оборвалось), запрос считается **ошибкой** и в статистику не попадает.
- Если запрос завершился ошибкой (не-2xx, таймаут, DNS), скрипт пишет об этом и продолжает со следующего запроса. Итог считается только по успешным запросам.

### Коды выхода

| Код | Значение |
|---|---|
| `0` | все запросы успешны |
| `1` | хотя бы один запрос завершился ошибкой |
| `2` | некорректные аргументы, например неверный URL или `-n 0` |

## Тесты

```bash
npm test
```

Тесты запускают локальный HTTP-сервер и проверяют:

- что тело скачивается полностью и байты считаются верно;
- что запросы идут строго последовательно;
- что скрипт следует редиректам;
- что ответы 404 и оборванные ответы считаются ошибками;
- формулы среднего времени и скорости;
- CLI: вывод в JSON и коды выхода.

## Структура

```
bin/speedtest.js     — CLI: разбор аргументов и вывод в консоль
src/speedtest.js     — логика: запросы, замер времени, подсчёт статистики
test/                — тесты (node:test)
```
